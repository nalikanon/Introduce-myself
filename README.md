# Apisit Yambangyang's Portfolio

เว็บแนะนำตัวเองเกี่ยวกับ AI Developer ของคุณ Apisit Yambangyang

## คุณสมบัติ

- โทนสีม่วงที่ทันสมัย
- หน้าแรกที่แนะนำตัวและข้อมูลเกี่ยวกับ AI Developer
- แสดงทักษะและโปรเจคที่สำคัญ
- การออกแบบที่ทันสมัยด้วย Tailwind CSS และ shadcn/ui

## เทคโนโลยีที่ใช้

- Next.js
- TypeScript
- Tailwind CSS
- Lucide React (ไอคอน)
- shadcn/ui components

## วิธีการรัน

```bash
# ติดตั้ง dependencies
npm install

# รันเซิร์ฟเวอร์สำหรับการพัฒนา
npm run dev

# เข้าถึงเว็บไซต์ที่
# http://localhost:3000
```
